## 写真の共通ルール（全スライド）
- 顔・人物は出さない。**着用した後ろ姿は使わない**（ウィッグはスタンドにかぶせた状態のみ）。目元のアップなし
- 手: ネイルなし（何も塗らない）、指輪・ブレスレット・腕時計は外す、ほくろ・傷が写らない角度
- 化粧品は容器・パレット・刻印・ブラシの柄の文字が写らないようにする（ブランドが分かるため）
- ハサミ・コーム・ピン・ダッカールもロゴ・刻印のない面を向ける
- X で使ったウィッグ・ウィッグスタンド・机・壁・タオル・小物は使わない（色違い・同じ型のウィッグも避ける）
- 背景は無地の布か紙。鏡・窓・部屋の特徴が写らない
- 位置情報をつけない、Exif を消す。写真はリポジトリに置かない

## 案A: ハーフアップの手順（ウィッグ・スタンドで）

前週 Threads 11/9 の「次に練習するアレンジ」の続き。前週の話題（固定道具の比較・お手入れ・分け目など）とは別の、アレンジ手順そのもの。

### スライド 1枚目（フック）
- 文字: **ウィッグのハーフアップ、上と下の「境目」を先に決めると崩れにくい**
- 写真: スタンドにかぶせたウィッグを横から。完成したハーフアップ（人物なし）

### スライド 2枚目
- 文字: **① 全体をとかしてから、耳の上あたりの高さでぐるりと分ける**／コームの先で線を引くように
- 写真: コームの先で毛束を上下に分けている手元（スタンド上）

### スライド 3枚目
- 文字: **② 下の髪はダッカールでよけておく**／混ざると、結んだあとに下の毛が引っぱられる
- 写真: 下半分をダッカールでまとめた状態のウィッグ（横から）

### スライド 4枚目
- 文字: **③ 上の髪を後ろで集めて、ゆるめに結ぶ**／きつく結ぶと、表面に筋が出やすい
- 写真: 上の毛束を後ろで集めている手元

### スライド 5枚目
- 文字: **④ 結び目のまわりを少しだけ指で引き出す**／ぺたんとした感じがやわらぐ
- 写真: 結び目の上の毛を指先でつまんでいる手元（指先のみ・爪が写らない角度）

### スライド 6枚目
- 文字: **⑤ ダッカールを外して、下の髪をとかしなおす**
- 写真: 下の髪をコームでとかしている手元

### スライド 7枚目（まとめ）
- 文字: **境目は「耳の上」くらいが、上下のバランスをとりやすかったです**／ウィッグの長さや毛量で変わるので、何回か試すのがおすすめ
- 写真: 完成したウィッグをスタンドの上で真後ろから（人物なし）

### キャプション
```
ウィッグのハーフアップの手順メモです。

前に、上と下の境目を決めずにざっくり持ち上げて結んだら、
下の髪まで引っぱられて、後ろがでこぼこになったことがあって。
それからは、先に境目を決めるようにしています。

1. 全体をとかして、耳の上あたりで分ける
2. 下の髪はダッカールでよけておく
3. 上の髪を後ろで集めて、ゆるめに結ぶ
4. 結び目のまわりを少しだけ引き出す
5. ダッカールを外して、下の髪をとかしなおす

境目の高さはウィッグの長さや毛量で変わるので、
スタンドの上で何回か試してみるのがおすすめです。

※「みお」は設定上の人物です。エピソードにはフィクションを含みます
```

## 案B: メイクブラシの形と使い分け

前週の「道具のお手入れ（洗う・乾かす）」とは別の、形ごとの使い分けの話。効果効能には触れず、「どこに・どう動かすか」だけを書く。

### スライド 1枚目（フック）
- 文字: **メイクブラシ、形で使い分けると迷わなくなりました**
- 写真: 毛先の形が違うブラシ4本を、毛先だけが見えるように並べた俯瞰（**柄は写さない**。柄が入る場合は無地のマスキングテープで覆う）

### スライド 2枚目
- 文字: **平たいブラシ**／広いところに色をのせる／まぶた全体の「最初の1色」に
- 写真: 平たいブラシの毛先のアップ（柄なし）

### スライド 3枚目
- 文字: **丸くて毛がやわらかいブラシ**／境目をぼかす／色と色のつなぎ目をくるくる
- 写真: 丸いブラシの毛先のアップ（柄なし）

### スライド 4枚目
- 文字: **細くて短いブラシ**／せまいところに色を置く／目のきわ・目尻などの細かいところに
- 写真: 細いブラシの毛先のアップ（柄なし）

### スライド 5枚目
- 文字: **斜めにカットされたブラシ**／線を引く／影を入れたいところに、角を当てて
- 写真: 斜めブラシの毛先のアップ（柄なし）

### スライド 6枚目
- 文字: **私の順番**／平たい → 細い → 斜め → 最後に丸いブラシでぼかす
- 写真: 文字だけのスライド（ブラシの形のイラストを矢印でつなぐ。顔のイラストは入れない）

### スライド 7枚目（まとめ）
- 文字: **同じ形でも毛のかたさで感触が違うので、手の甲で動かして試してから**
- 写真: 文字だけのスライド

### キャプション
```
メイクブラシの使い分けのメモです。

前はなんとなく手に取ったブラシで全部やっていて、
ぼかしたいところに色がたまってしまうことがありました。
形ごとに役割を決めてから、手が止まらなくなりました。

・平たい: 広いところに色をのせる
・丸くてやわらかい: 境目をぼかす
・細くて短い: せまいところに色を置く
・斜め: 線を引く

順番は
平たい → 細い → 斜め → 最後に丸いブラシでぼかす
で落ち着いています。

同じ形でも毛のかたさで感触が違うので、
手の甲で動かしてみてから使っています。

みなさんの「この形はこう使う」も聞いてみたいです。

※「みお」は設定上の人物です。エピソードにはフィクションを含みます
```
