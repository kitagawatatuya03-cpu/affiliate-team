## 写真の共通ルール（全スライド）
- 顔・人物は出さない。**着用した後ろ姿は使わない**（ウィッグはスタンドにかぶせた状態のみ）。目元のアップなし

- 位置情報をつけない、Exif を消す。写真はリポジトリに置かない

## 案A: ウィッグで編み込みの練習（スタンドで）

前週 Threads 11/9 の「どれがいちばんむずかしい？」の続き。

### スライド 1枚目（フック）
- 文字: **編み込みは、「三つ編み」が均一にできてからのほうが早かった**
- 写真: スタンドにかぶせたウィッグのサイドに、編み込みが1本入っているところ（横から・人物なし）

### スライド 2枚目
- 文字: **① まずは毛束を3つに分けて、三つ編みだけ練習**／3つの量をそろえるのがいちばん大事
- 写真: 3つに分けた毛束を指で持っている手元

### スライド 3枚目
- 文字: **② 編み込みは、編むたびに横の毛を少しずつ足す**／足す量は毎回同じくらいに
- 写真: 横から毛をすくって足している手元

### スライド 4枚目
- 文字: **③ 引っぱる強さは「ゆるめで一定」**／強く引くと、ウィッグの毛にうねりが残ることも
- 写真: 編み進めた途中のウィッグ（横から）

### スライド 5枚目
- 文字: **④ 最後まで編んだら、毛先をゴムでとめる**
- 写真: 毛先をゴムでとめている手元

### スライド 6枚目
- 文字: **⑤ 編み目をほんの少しずつ指で引き出す**／一気に引くとほどけるので、下から順に
- 写真: 編み目をつまんで広げている手元（指先のみ・爪が写らない角度。難しければ編み目のアップだけ）

### スライド 7枚目（まとめ）
- 文字: **うまくいかない日は、三つ編みに戻って練習**／編み込みはその「足し算」でした
- 写真: 完成した編み込みのウィッグをスタンドの上で斜め後ろから（人物なし）

### キャプション
```
ウィッグで編み込みを練習したときのメモです。

いきなり編み込みから始めたら、
足す毛の量がばらばらで、途中から太さが変わってしまって。
三つ編みに戻って、3つの毛束の量をそろえる練習をしてから、ようやく形になりました。

1. 毛束を3つに分けて、三つ編みだけ練習
2. 編むたびに横の毛を少しずつ足す
3. 引っぱる強さはゆるめで一定に
4. 毛先をゴムでとめる
5. 編み目を下から少しずつ引き出す

強く引っぱりながら編むと、ほどいたあともウィッグの毛にうねりが残ることがあるので、
ゆるめに編むようにしています。

※「みお」は設定上の人物です。エピソードにはフィクションを含みます
```

## 案B: アイシャドウのグラデーションを手の甲で練習

前週の「手の甲の色見本」（ウィッグとの色合わせ＝色を選ぶ話）とは別の、選んだ色を「つなぐ」練習の話。効果効能には触れない。

### スライド 1枚目（フック）
- 文字: **グラデーションの練習、まぶたの前に「手の甲」でやっています**
- 写真: 手の甲に、明るい色から暗い色へ3色がつながったグラデーション（爪は入れない・容器なし）

### スライド 2枚目
- 文字: **① いちばん明るい色を、広めにのせる**
- 写真: 手の甲に明るい色を1色だけ、横長にのせたカット

### スライド 3枚目
- 文字: **② まん中の色を、半分重ねるようにのせる**／最初の色を全部おおわない
- 写真: 明るい色の上に、まん中の色を半分重ねたカット

### スライド 4枚目
- 文字: **③ いちばん暗い色は、端に少しだけ**
- 写真: 3色をのせた直後（まだぼかしていない状態）

### スライド 5枚目
- 文字: **④ 境目だけを、丸いブラシでくるくるぼかす**／色をのせたところ全体はさわらない
- 写真: ぼかす前／ぼかした後を左右に並べた比較（文字入れ「前」「後」）

### スライド 6枚目
- 文字: **失敗例: 暗い色をのせすぎると、ぼかしても境目が残る**／足りなければあとから足す
- 写真: 暗い色が多すぎた失敗のスウォッチ（文字入れ「失敗」）

### スライド 7枚目（まとめ）
- 文字: **手の甲で「重ねる幅」の感覚をつかんでから、本番へ**
- 写真: 文字だけのスライド

### キャプション
```
アイシャドウのグラデーションの練習メモです。

本番でいきなりやると、暗い色をのせすぎて、
ぼかしても境目がくっきり残ってしまうことがあって。
いまは先に手の甲で練習してから始めています。

1. いちばん明るい色を広めにのせる
2. まん中の色を半分重ねる
3. いちばん暗い色は端に少しだけ
4. 境目だけを丸いブラシでぼかす

暗い色は「足りなければあとから足す」くらいがちょうどよかったです。

手の甲はまぶたと感触が違うので、あくまで重ねる幅とぼかし方の練習用にしています。

※「みお」は設定上の人物です。エピソードにはフィクションを含みます
```

### ハッシュタグ（7個）
