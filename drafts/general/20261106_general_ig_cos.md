## 案A: ノウハウ「ウィッグの毛量を減らすときの順番」

### 1枚目（フック）
- 文字: **ウィッグが「もっさり」するとき、切る前に試したい順番**
- 写真: ウィッグスタンドに乗せた、毛量の多い状態のウィッグ（横から）

### 2枚目
- 文字: **① まずはとかして、クセと絡まりをとる**／絡まったままだと、多く見えているだけのことも
- 写真: ウィッグ用のブラシでとかしている手元

### 3枚目
- 文字: **② ブロックに分けてクリップでとめる**／内側から少しずつ作業するため
- 写真: 毛束をクリップで分けた状態のウィッグスタンド

### 4枚目
- 文字: **③ 内側の毛を少しずつすく**／表面は最後まで触らないほうが失敗しにくかったです
- 写真: すきバサミを持った手元（刃先はウィッグの内側）

### 5枚目
- 文字: **④ こまめに離れて全体を見る**／近くで見ているとすきすぎに気づきにくい
- 写真: 少し離れた位置からウィッグスタンド全体を撮ったカット

### 6枚目
- 文字: **⑤ 最後にスプレーやアイロンで形を整える**／ウィッグの耐熱温度は必ず表示を確認
- 写真: 整えたあとのウィッグ（1枚目と同じ角度で比較）

### 7枚目（まとめ）
- 文字: **切った毛は戻らないので「少しずつ」がいちばんの近道でした**
- 写真: 切った毛を小皿に集めた手元

### キャプション
```
ウィッグの毛量調整のメモです。

前に一気にすいて、表面がスカスカになったことがあって。
それからは、この順番で少しずつ進めるようにしています。

1. とかして絡まりをとる
2. ブロックに分けてクリップでとめる
3. 内側から少しずつすく
4. こまめに離れて全体を見る
5. 最後に形を整える

アイロンやドライヤーを使うときは、ウィッグの耐熱温度の表示を確認してからにしています。

あくまで私のやり方なので、もっといい方法があれば教えてください。

※キャラ設定で運用しているアカウントです
```

## 案B: 失敗談「前髪を切りすぎたウィッグを、どうにかした話」

### 1枚目（フック）
- 文字: **ウィッグの前髪、切りすぎました。ここからの立て直し記録**
- 写真: ウィッグスタンドに乗せた、前髪が短くなったウィッグ（正面）

### 2枚目
- 文字: **原因: ウィッグをまっすぐ下ろしたまま、真横に切ったこと**／毛先が乾くと思ったより上がりました
- 写真: 前髪部分のアップ

### 3枚目
- 文字: **立て直し①: 前髪を斜めに流すデザインに変更**／分け目の位置を少しずらしました
- 写真: コームで分け目を作っている手元

### 4枚目
- 文字: **立て直し②: 毛先を縦にハサミを入れて、ラインをやわらかく**
- 写真: ハサミを縦に入れている手元

### 5枚目
- 文字: **立て直し③: 形をつけて固定**
- 写真: 整えたあとのウィッグ（1枚目と同じ角度）

### 6枚目（次回への教訓）
- 文字: **次からは「長めに切って、少しずつ詰める」。クリップで仮どめしてから切る**
- 写真: クリップとハサミを並べた作業机

### キャプション
```
ウィッグの前髪、切りすぎました。

まっすぐ下ろしたまま真横に切ったら、
思っていたより短くなってしまって。

今回は、
・斜めに流すデザインに変える
・毛先に縦にハサミを入れてラインをやわらかくする
・形をつけて固定する
で、なんとか使える形に戻せました。

次からは長めに切って少しずつ詰めること、
切る前にクリップで仮どめして長さを確かめることにします。

同じ失敗をしたことがある方、どうやって直したか聞いてみたいです。

※キャラ設定で運用しているアカウントです
```

## 補足（compliance・オーナー向け）
- 案A の耐熱温度の注意は安全上の一般的な注意で、特定商品の性能をうたうものではない
- 「#前髪カット」は人の髪型の投稿も多いタグのため、不要なら外す（その場合6個）
- ウィッグをかぶった着用写真は使わない（顔なし・身体の写り込み防止）
