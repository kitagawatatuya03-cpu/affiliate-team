## 11/4（水）コツ: 色を見る光

### 案A
```
メイクの色を選ぶとき、手の甲にのせて
自然光と室内の照明、両方で見るようにしています。

部屋の明かりだけで決めたら、
外の光ではまったく違う色に見えたことがあって。
```

### 案B
```
ウィッグの色に合わせてメイクの色を決めるとき、
「同じ色」より「ほんの少し暗い色」のほうが合わせやすかったです。

同じ明るさだと、ウィッグとなじみすぎてぼやけて見えがちでした。
```

## 11/7（土）コツ: 道具のお手入れ

### 案A
```
メイクのスポンジとブラシは、使ったらそのつど洗って、
風通しのいいところでしっかり乾かすようにしています。

洗うのをためると、次に使うとき色が混ざってしまって。
地味だけど、続けると準備がラクです。
```

### 案B
```
ウィッグをとかすとき、毛先 → 中間 → 根元の順番にしています。

根元からいっきにブラシを入れると、
途中で引っかかって毛が抜けやすかったので。
```
