## 案A: ノウハウ「ウィッグで高めのポニーテールを作る手順」

### 1枚目（フック）
- 文字: **ウィッグの高めポニーテール、地毛のように引っぱらないのがコツでした**
- 写真: スタンドにかぶせたウィッグで、完成したポニーテールを斜め後ろから

### 2枚目
- 文字: **① まずはしっかりとかす**／毛先 → 中間 → 根元の順で
- 写真: ウィッグ用ブラシで毛先をとかす手元

### 3枚目
- 文字: **② 結ぶ位置にピンで目印**／左右の高さがそろいやすい
- 写真: 結ぶ位置にピンを1本さしたウィッグ（後ろから）

### 4枚目
- 文字: **③ 表面・内側の2段に分けて結ぶ**／いっきに結ぶと、えり足がたるみやすかった
- 写真: 内側だけ先に結んだ状態をダッカールで見せるカット

### 5枚目
- 文字: **④ 結び目を毛束で巻いて隠し、ピンで固定**
- 写真: 毛束を結び目に巻いている手元

### 6枚目
- 文字: **⑤ えり足の浮きはピンで内側にとめる**
- 写真: えり足部分のアップ（スタンド上）

### 7枚目（まとめ）
- 文字: **かぶったときの後ろ姿**
- 写真: ウィッグをかぶった後ろ姿（首から上の髪だけ。顔・横顔が写らない角度）

### キャプション
```
ウィッグの高めポニーテールの手順メモです。

地毛のつもりで強く引っぱって結んだら、
えり足がたるんで、ネットが見えそうになったことがあって。
それからは2段に分けて結ぶようにしています。

1. しっかりとかす（毛先から）
2. 結ぶ位置にピンで目印
3. 内側 → 表面の2段で結ぶ
4. 結び目を毛束で巻いて隠す
5. えり足の浮きを内側にとめる

スタンドの上で作ってからかぶると、後ろもきれいに確認できます。

※キャラ設定で運用しているアカウントです
```

## 案B: 比較「アレンジの固定、ゴム・ピン・スプレーの使い分け」

### 1枚目（フック）
- 文字: **ウィッグのアレンジ、何で固定する？ 3つを比べてみました**
- 写真: ヘアゴム・アメピン・ヘアスプレー（ラベルを裏に向ける）を並べた俯瞰

### 2枚目
- 文字: **ゴム**／○ 結ぶだけで早い　△ 結び目が見えやすい→毛束で巻いて隠す
- 写真: ゴムで結んだ毛束の手元

### 3枚目
- 文字: **ピン**／○ 形を細かく作れる　△ 数が増えると重くなる→見えない内側に
- 写真: 内側にピンをさしている手元

### 4枚目
- 文字: **スプレー**／○ 表面の毛の飛び出しをおさえる　△ かけすぎると固まってとかしにくい→少し離して軽く
- 写真: スタンドのウィッグに離れた位置からスプレーしている手元

### 5枚目
- 文字: **私の使い分け**／土台はゴム → 形はピン → 仕上げにスプレーを少し
- 写真: 文字だけのスライド（イラストで3ステップ）

### 6枚目（まとめ）
- 文字: **ウィッグの素材によって合う・合わないがあるので、目立たないところで試してから**
- 写真: 完成したアレンジのウィッグ（スタンド上・横から）

### キャプション
```
ウィッグのアレンジを固定するとき、
ゴム・ピン・スプレーをどう使い分けるかのメモです。

ゴム: 早いけど結び目が見えやすい
ピン: 形を作りやすいけど、増えると重い
スプレー: 表面を整えやすいけど、かけすぎると固まる

いまは
土台はゴム → 形はピン → 仕上げにスプレーを少し
で落ち着いています。

スプレーはウィッグの素材によって相性があるので、毛先の目立たないところで試してから使っています。

みなさんの固定方法も聞いてみたいです。

※キャラ設定で運用しているアカウントです
```

## 補足（compliance・オーナー向け）
- 後ろ姿の写真は、写真の人物が特定されない角度（顔・横顔・耳まわりの特徴が写らない）で撮るよう指示。X の写真と服・背景・ウィッグが同じにならないよう注意
- スプレーは一般名詞のみ。商品の効果（「1日崩れない」など）には触れていない
