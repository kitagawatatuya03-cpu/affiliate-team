## Instagram

### ユーザーネーム案（3つ。どれも空きは未確認。登録前にオーナーが確認してください）
| 案 | ユーザーネーム | ねらい | 注意 |
|---|---|---|---|
| A（推奨） | `mio_wig_note` | 「ウィッグのノート」。記録アカウントらしく、テーマが一目で分かる | 「mio」は X と共通。ukkari / jimu は含まないため、ID だけでの直接の結びつきは弱い |
| B | `mio_cosmake_memo` | コスメイクのメモ。メイク寄りの投稿が多くなる場合向け | 同上 |
| C | `kami_to_iro_note` | 「髪と色のノート」。みおの名前を入れず、X との結びつきを最も弱くする案 | 名前と ID が一致しないため、見つけてもらいにくい |

- 3案とも「ukkari」「jimu」「事務」「夜」「大人」など X 側の語は使っていない
- 身バレ対策を最優先するなら C、見つけてもらいやすさとのバランスなら A

### 名前（表示名）
- 案1（推奨）: `みお｜コスメイクとウィッグの記録`
- 案2: `みお｜ウィッグアレンジ記録`
- 補足: X の表示名は「みお（キャラ）｜大人のコスプレイヤー」。「みお」＋「コスプレイヤー」がそろうと検索で並びやすいため、表示名には「コスプレイヤー」を入れていない

### プロフィール文

案1（推奨・約90字）
```
会社員のコスプレイヤー
コスメイクとウィッグアレンジの手順・失敗・比較を記録しています
顔出しはしていません（写真はウィッグ・手元・道具のみ）
※キャラ設定で運用しているアカウントです
```

案2（約75字）
```
ウィッグアレンジとコスメイクの練習ノート
うまくいった手順も失敗も、そのまま残しています
顔出しなし
※キャラ設定で運用しているアカウントです
```

- リンク欄: **空欄**
- 年齢設定（22歳など）・「事務」は X 側の設定と結びつくため書かない
- 化粧品の効果効能を思わせる言葉（「美肌」「盛れる」など）は入れていない

### ハイライトの分け方案
| ハイライト名 | 中身 | カバー画像（顔なし） |
|---|---|---|
| ウィッグアレンジ | まとめ髪・編み込みなどの手順（スタンド上・後ろ姿） | スタンドにかぶせたウィッグ |
| ウィッグのお手入れ | とかし方・保管・洗い方の手順 | ウィッグ用ブラシ |
| メイク手順 | 手順のイラスト・文字だけのスライド | メイクブラシを並べた写真 |
| 色見本 | 手の甲のスウォッチ、ウィッグの色との合わせ方 | 手の甲のスウォッチ |
| 道具 | 使っている道具（店名・ブランド名・商品名は出さない） | 道具の並び |
| 失敗メモ | 失敗とその直し方 | ピンとコーム |
| Q&A | ストーリーズの質問への回答（手順・道具の質問のみ） | 文字だけの画像 |

- Q&A では、容姿・身体・年齢・地域・イベントの場所・「顔を見せて」系の質問には答えない（brand-voice のリプ対応に準じる）
- 商品名を聞かれた場合も、収益化前は答えない（「商品名はお伝えしていません」で統一）
