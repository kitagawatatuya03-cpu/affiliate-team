# 数値データの置き場所

週1回（日曜）、以下をダウンロードしてここに置くか、チャットに貼ってください。analyst が月曜に週次レポートを作ります。

| ファイル | 取り方 | ファイル名 |
|---|---|---|
| X の投稿ごとの数字 | X のアナリティクス（プレミアムが必要な場合あり）→ 投稿データを CSV でエクスポート | `YYYYMMDD_x_posts.csv` |
| X のフォロワー数 | プロフィールの数字をメモ | `YYYYMMDD_x_followers.txt` |
| FANZA の成果 | DMMアフィリエイト管理画面 → レポート（クリック数・成果数・報酬）→ CSV | `YYYYMMDD_fanza_report.csv` |

X のアナリティクスが使えない場合は、投稿ごとの「表示回数・いいね・リンクのクリック数」を手でメモしたものでも大丈夫です。
元データのファイルは analyst が編集しません。
