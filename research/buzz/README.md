# バズ投稿リサーチ（Instagram・Threads）

オーナー指示（2026-10-27）: 投稿前に、Instagram と Threads でバズっている投稿を **10件** 見つけるまでリサーチを続ける。

## バズ投稿の定義（オーナー決定）
1. **再生数（閲覧数）がフォロワー数の2倍以上** の投稿に限る
2. フォロワー **1万人以上** のアカウントは優先度を下げる
3. フォロワー **1万人未満** のアカウントは優先度を上げる

## 記録する項目（1投稿1ファイル: `YYYYMMDD_媒体_番号.md`）
| 項目 | 内容 |
|---|---|
| 媒体 | Instagram / Threads |
| 投稿URL | |
| アカウント | @ID、ジャンル |
| フォロワー数 | 確認日つき |
| 再生数（閲覧数） | 確認日つき |
| 倍率 | 再生数 ÷ フォロワー数（2.0以上が条件） |
| 優先度 | 高（1万人未満）／低（1万人以上） |
| 投稿の型 | 例: あるある、失敗談、アンケート、スライド、テキストのみ |
| 冒頭（フック） | 最初の1行・最初の1枚で何を言っているか |
| バズった理由の仮説 | |
| みおのアカウントに応用するなら | ※丸写しはしない。型だけ借りる |

## 一覧
`一覧.md` に 10件の表と、共通する型のまとめを置く。

## 対象ジャンル（オーナー決定 2026-10-27）
- 働く女性の日常・うっかり（みおの日常投稿の参考）
- 恋活・婚活（12月以降の一般ラインの準備）

## 進め方（オーナー決定 2026-10-27 変更）
- この環境からは instagram.com・threads.com に接続できない（プロキシ 403）ため、**オーナーがアプリで投稿を見つけ、URL かスクリーンショットと数字を送る → ディレクターが定義に沿って判定・分析・保存** する
- 定義を満たした投稿が **10件** そろうまで続ける（満たさなかった投稿も「不採用」として一覧に記録する）
- 再生数（閲覧数）が見えない投稿は判定できないため「判定不能」として記録し、10件には数えない
