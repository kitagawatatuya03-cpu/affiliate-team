# バズ投稿リサーチ（Instagram・Threads）

オーナー指示（2026-10-27）: 投稿前に、Instagram と Threads でバズっている投稿を **10件** 見つけるまでリサーチを続ける。

## バズ投稿の定義（オーナー決定）
1. **再生数（閲覧数）がフォロワー数の2倍以上** の投稿に限る
2. フォロワー **1万人以上** のアカウントは優先度を下げる
3. フォロワー **1万人未満** のアカウントは優先度を上げる

## 記録する項目（1投稿1ファイル: `YYYYMMDD_媒体_番号.md`）
| 項目 | 内容 |
|---|---|
| 媒体 | Instagram / Threads |
| 投稿URL | |
| アカウント | @ID、ジャンル |
| フォロワー数 | 確認日つき |
| 再生数（閲覧数） | 確認日つき |
| 倍率 | 再生数 ÷ フォロワー数（2.0以上が条件） |
| 優先度 | 高（1万人未満）／低（1万人以上） |
| 投稿の型 | 例: あるある、失敗談、アンケート、スライド、テキストのみ |
| 冒頭（フック） | 最初の1行・最初の1枚で何を言っているか |
| バズった理由の仮説 | |
| みおのアカウントに応用するなら | ※丸写しはしない。型だけ借りる |
