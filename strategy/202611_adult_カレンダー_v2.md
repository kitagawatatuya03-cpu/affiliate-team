## 凡例

| 投稿の型 | 内容 |
|---|---|
| 固定 | 固定投稿（戦略 v2 第6章の文案。アダルト要素なし、リンクなし、画像なし） |
| 日常 | 天然・うっかりのコスプレの日常（衣装づくり・ウィッグ・撮影・仕事との両立）。案件・作品名・サービス名・店名に触れない。PR 不要、**18歳未満閲覧禁止は必須** |
| あるある | コスプレのやらかしあるある（創作） |
| 問いかけ | 2択アンケート・質問 |
| 振り返り | 1週間のやらかしまとめ・お礼 |
| 案件（動画） | 冒頭に PR。日常の話 →「そういえば…」で FANZA 作品の紹介。公式素材のみ、センシティブ設定 ON、写真は付けない。**リンクは自分のリプ欄に1本**（リプにも PR・18歳未満閲覧禁止） |
| 案件（動画・コスプレ） | 上に加えて、**衣装の作り込み・小物の再現度の話だけ**。「私も同じ衣装を持ってる」「着てみたい」など写真の人物と作品をつなぐ書き方は禁止。本文に「※写真の人物はこの作品に出演していません」 |
| セール告知枠 | 動画枠の一部。日付はオーナー確認（FANZA のセール時期は未確認）。セールがなければ「代わりの切り口」で通常の動画紹介に。未確認のまま「セール中」「期間限定」と書かない |

| 写真の欄 | 意味 |
|---|---|
| なし | 写真を付けない（アイコンのみ表示） |
| 人物なし | 衣装・布・ウィッグ（スタンドのみ）・作業机などの写真。版権グッズ・イベントの入場証・部屋の特徴を写さない |
| **顔あり** | 実写のコスプレ写真（オーナー本人・露出のない汎用コス）。**週1枚まで**。photo-consent のチェック済みであること。**案件投稿との間は24時間以上あける** |

| 時間帯 | 目安 |
|---|---|
| 朝 | 7:30〜8:30（出勤前） |
| 昼 | 12:00〜13:00（昼休み） |
| 夜 | 21:00〜23:00（案件投稿はこの枠のみ） |

- 時刻は枠の中で毎日ずらす
- キャラの生活: 平日は会社の事務職（業種・会社・地域は出さない）、休日に衣装づくり・宅コス撮影。曜日固定の行動パターン（毎週〇曜にどこへ行く等）は作らない
- イベント参加の話は**事前・当日に書かない**。書くなら数日後に、イベント名・会場・日付・衣装を出さずに
- 案件リンクは1日1本まで、2日連続にしない
