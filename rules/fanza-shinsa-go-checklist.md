# FANZA 審査通過後にオーナーが確認すること

審査に通ったら、DMMアフィリエイトの管理画面で以下を確認し、結果（または規約ページの文章）をディレクターに渡してください。
compliance がこの内容で第2週の案件投稿を最終チェックします。

## 1. 規約の原文（文章をコピーしてチャットに貼る）
- [ ] DMMアフィリエイト 利用規約（全文）
- [ ] 禁止事項・ガイドライン（SNS／X での掲載に関する部分）
- [ ] 素材（サンプル画像・サンプル動画）の利用ルール

## 2. 特に見てほしい点
- [ ] X への掲載が可能か（アダルト作品のリンクを X に載せてよいか）
- [ ] 短縮URLの利用可否
- [ ] サンプル画像・サンプル動画を X に投稿してよいか（加工の可否、モザイクの扱い）
- [ ] 禁止ワード・禁止表現の一覧があるか
- [ ] PR 表記についての指定（文言・位置）があるか

## 3. 報酬（ライブチャット）
- [ ] FANZAライブチャットの成果地点（初回購入／ポイント購入／登録 など）
- [ ] 継続報酬があるか（紹介した人が使い続けると報酬が続くか）、その期間と料率
- [ ] FANZA動画の料率

## 4. アフィリエイトリンクの作り方
- [ ] 作品ページのリンクの作り方（管理画面の「リンク作成」など）
- [ ] FANZAライブチャットのリンクの作り方

## 5. 第2週に紹介する作品を選ぶ（2本）
選ぶときのルール:
- 未成年を想起させる作品（学生・制服・年齢を若く見せる設定）は除外
- 病院・ナースもの、医療系の設定の作品は除外
- 無修正・海外配信は除外（FANZA 内は基本的に該当しない）
- 11/9: 新作から1本 ／ 11/11: ストーリーをじっくり追える作品を1本
- 作品ごとに「作品名」「価格（セール中なら条件と期間）」「公式の紹介文から1行」「作品ページURL」をメモして渡す
