# コンプライアンス チェックリスト

> 規約や法律は改定されます。月1回、compliance エージェントに最新版を確認させてください。最終的な法的判断が必要なときは専門家に相談してください。

## 共通
- [ ] 案件投稿に「PR」「広告」の表記がある（ステマ規制）
- [ ] PR表記なしの日常投稿は、案件・リンク・作品名・サービス名・セール情報に一切触れていない（触れていたら案件投稿扱いでPR必須）
- [ ] 断定・誇大表現がない（景品表示法：優良誤認・有利誤認）
- [ ] 料金・無料条件が正確（「初回無料」の条件などを省略していない）
- [ ] ASPの規約（SNS掲載の可否、使える素材、禁止ワード、リスティング・指名KW）に違反していない
- [ ] 他人の画像・動画を無断で使っていない

## 未成年保護（1つでも該当したら即NG）
- [ ] 未成年を想起させる語句・設定・画像がない
- [ ] 年齢表記・利用制限の表示がある

## マッチング・出会い系
- [ ] 運営会社がインターネット異性紹介事業の届出済みである（researcher の審査記録あり）
- [ ] 「18歳未満の方は利用できません」の表示がある
- [ ] 「必ず会える」「〇〇とすぐ会える」などの表現がない
- [ ] 一般ラインでは性的なニュアンスがない（Meta / TikTok の規約）
- [ ] TikTok では、ブランデッドコンテンツの規約で該当カテゴリが許可されている

## ライブチャット
- [ ] アダルト系は X のアダルトアカウントのみ
- [ ] 18歳未満閲覧禁止の表示がある
- [ ] 料金体系（ポイント制など）を誤認させない

## X（アダルトライン）
- [ ] センシティブ設定を ON にする前提になっている
- [ ] アイコン・ヘッダー・固定投稿にアダルト要素がない
- [ ] 同一文面の大量投稿・自動リプライなどのスパム行為がない

## 判定
- **OK**: そのまま承認へ
- **要修正**: 修正案つきで writer に差し戻す
- **NG**: 理由を記録して破棄
