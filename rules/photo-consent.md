# 実写写真の同意と安全チェック（案B：顔ありの実写）

オーナー決定（2026-10-27）: アイコン等に実写（顔あり）を使う。写るのはオーナー本人、または許可を得た知り合い。

> 法的な判断が必要な場合は専門家に相談してください。以下は運用上の最低限のチェックです。

## 1. 同意（知り合いが写る場合は必須。口頭ではなく書面・メッセージで残す）
- [ ] 写る人が **18歳以上** であることを確認した（身分証で確認、記録は最小限）
- [ ] **アダルト系アフィリエイトの X アカウント** に使うことを説明し、同意を得た（「SNSに使う」だけでは不十分）
- [ ] 使う場所: アイコン／ヘッダー／投稿の写真 のどれに使うか
- [ ] 使う期間と、**同意の撤回** ができること、撤回されたら差し替える期限（例: 7日以内）
- [ ] 「みお」というキャラ設定（24歳・医療事務・天然）で使うこと、本人の実際の年齢・職業とは違うこと
- [ ] 本人が投稿文を書くわけではないこと、DM対応はしないこと
- [ ] 報酬の有無と金額
- [ ] 本人が特定された場合の対応（アカウントの写真をすぐ外す など）
- [ ] 同意書（またはメッセージのスクリーンショット）を **このリポジトリ以外の安全な場所** に保管した（GitHub に個人情報を置かない）

## 2. オーナー本人が写る場合
- [ ] 顔写真から本人が特定されるリスク（職場・家族・知人、画像検索）を理解した
- [ ] 本名・勤務先・住んでいる地域が分かる情報を、写真にも投稿にも出さない

## 3. 写真そのもののチェック（1枚ごと）
- [ ] 露出なし・性的なポーズなし（X はプロフィール画像・ヘッダーのアダルト要素を禁止）
- [ ] 未成年に見える要素なし（学生風の服装、幼く見せる加工・ポーズ）
- [ ] ナース服・白衣なし。**実在の職場の事務服・名札・ロゴを写さない**
- [ ] 背景から場所が分からない（窓の外の景色、駅、建物、郵便物、部屋の特徴）
- [ ] **位置情報（EXIF）を削除** してからアップロード
- [ ] 他人が写り込んでいない
- [ ] 過度な加工で別人に見せていない（実在の人物として誤認を招く）

## 4. 運用ルール（実写に変えたことで強化）
- 案件投稿（作品・ライブチャット）には **写真を付けない**。写真は日常投稿のみ
- 「紹介するサービスに私は出ていません」を固定投稿に必ず残す
- 出演者・相手役に見える表現は引き続き禁止（「私もいるよ」「話そ」「待ってるね」）
- DM は受け付けない。写真への性的なリプには反応しない
- 写っている人から撤回の連絡があったら、最優先で写真を外す
