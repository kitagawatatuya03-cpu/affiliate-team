## 2. プロフィール（写真なし版）

- **判定: 要修正**（修正は「学生を連想させない」ための1か所のみ）
- 該当したチェック項目
  - 未成年保護: 未成年を想起させる語句・設定がない → **未成年の想起はない**（22歳は成年。年齢を若く見せる語もない）。NG には当たらない
  - 未成年保護: 年齢表記・利用制限の表示 → 「18歳未満閲覧禁止」あり
  - 共通: PR 表記 →「PRを含みます」あり（CLAUDE.md のプロフィール必須表記）
  - 実写・コスプレ: 注意書きが揃っている → 写真がない間は「創作」の明記で足りる（下記）
- 理由
  1. **「22歳」は大学4年生の年齢でもある**。原案はプロフィールのどこにも社会人・会社員である旨がなく、「22歳設定のコスプレイヤー」だけだと「女子大生レイヤー」と読まれる余地がある。オーナー決定 #18 は「社会人として描き、学生・幼さを連想させる要素は入れない」としているので、**冒頭に「会社員」を入れて学生の読み方を消す**。あわせて ID の「jimu」とも筋が通る（業種・会社名は出さない。brand-voice どおり）
  2. 文字数を増やさないために「、どこかで」を削り、「休日コスプレの日常」を「コスプレの日常」にした（「休日」は冒頭に移動）。口調の変更は最小限。writer が別の削り方をしたい場合は、注意書きの行は削らないこと
  3. 「コスプレイヤーキャラ」は「実在のコスプレイヤーが演じるキャラ（中の人がいる）」とも読めた。推奨版は「〜コスプレイヤーのキャラ『みお』」として、みお自体がキャラであることを先に示した
  4. 「若く見える方向」の点検: 「うっかり」「天然」「やらかす」は大人の失敗談の範囲で、幼い口調・年齢を下げる語（新卒・1年目・○年生・ちゃん付け等）はない。問題なし。今後の日常投稿でも「新卒感」「社会人1年目」の強調はしないこと（戦略 v2 第3章）
- **写真なし版の注意書き（写真の文言なし）で足りるか**
  - **足りる。むしろ写真の文言を入れてはいけない**。写真がないのに「写真は同意済みの実在の人物」と書くと事実と違う表示になる（#13 で「実在の人物とは関係ありません」を削ったのと同じ種類の問題を逆向きに起こす）
  - 写真なしの間は「みお」は実在しないキャラで、出演のしようがないため、「紹介先に出演していません」「投稿は運営者が作成」も必須ではない。「キャラ設定のアカウント・内容は創作です」で、存在しない人物を装っていないことは示せている
  - ただし足りるのは **アイコン・ヘッダー・投稿のどこにも人物（実写）が出ていない間だけ**。実写が1枚でも出る時点で写真あり版に替える（上記 11/7 の前提条件 3）
  - 「実在の人物とは関係ありません」は写真なし版にも **入れない**（11/7 で事実でなくなり、また差し替えが必要になる）
- 修正案: 冒頭の推奨版

## 3. プロフィール（写真あり版）

- **判定: 要修正**＋**専門家確認推奨**

  - 共通: PR 表記 → あり。未成年保護: 18歳未満閲覧禁止 → あり
  - 未成年保護 → 2章と同じ（学生連想の修正が必要）
- 理由
  1. 1行目は写真なし版と共通なので、2章の理由1〜3の修正を同じく反映する（文字数は152字のまま）
  2. **前回 photo review の推奨を満たしているか** → 満たしている
     - 創作: 「キャラ設定・内容は創作」「22歳設定」
     - 写真は同意済みの実在の人物: あり
     - 投稿は運営者が作成: あり（写る人がオーナー本人〔#21〕でも事実として正しい）

  3. 「紹介先に」は「リンク先のサイト」とも読めるが、作品・サービス両方を含む意味で通じる。固定投稿で「紹介する作品・サービス」と明記しているので、プロフィールは文字数優先で「紹介先」のままでよい
  4. **専門家確認推奨を外せない理由**（前回から変わらず）: 実在の人の顔写真＋架空の年齢・職業＋アダルト案件の紹介、という組み合わせが X の deceptive identities の「存在しない人物を装う」に当たらないかは、原文未確認で判断できない。コスプレ版では FANZA のコスプレ作品・コスプレ配信の出演者と誤認される危険が医療事務版より高い（戦略 v2 C4・C5）
  5. 「紹介先に写真の人物は出演していません」は、11/7 の前提条件 2 の確認が済んだ場合のみ事実として書ける

## 4. 固定投稿

- **判定: 要修正**＋**専門家確認推奨**
- 該当したチェック項目
  - 共通: PR 表記 → 【PR】あり。ただし CLAUDE.md は固定投稿に「PRを含みます」等の **アカウント全体の注意書き** を求めている
  - 実写・コスプレ: 注意書き4点 → 揃っている
  - X（アダルトライン）: 固定投稿にアダルト要素がない → なし（リンク・作品名・性的な語なし）
  - 未成年保護 → 18歳未満閲覧禁止あり。未成年を想起させる語なし
- 理由
  1. 【PR】は「この投稿が広告」という意味には読めるが、「このアカウントの投稿には PR が含まれる」という全体の注意書きにはなっていない。プロフィールはスマホの表示によって改行がつぶれ、読まれにくいこともあるので、**固定投稿にも「PRを含みます」を入れる**（最終行に追加。X換算 244 → 約258）。【PR】は冒頭に残す（厳しい側）
  2. 年齢・職業・エピソードが創作であること、写真と投稿者の関係、出演していないことは前回推奨どおり。主語が「写真の人物は」になっていて、前回指摘した「私」「本人」のあいまいさはない
  3. 「22歳設定」「会社員」を固定投稿に書かないのは問題なし（プロフィールにあり、固定投稿では「年齢・職業は創作」と明記）
  4. 「実在のコスプレイヤー・イベント・作品とは関係ありません」を入れたい場合は、文字数が足りないので2投稿目（スレッド）に分ける（戦略 v2 第6章）。ただし「実在のコスプレイヤーとは関係ありません」は、写真の人物（実在・コスプレ姿）と矛盾して読めるので、使うなら「**実在のコスプレイヤーの別アカウントではありません**」のように書く。必須ではない
  5. 専門家確認推奨の理由は3章の4と同じ
- 修正案: 冒頭の推奨版（固定投稿）

## 6. 論点ごとの結論（要約）

1. **前回 photo review の推奨をコスプレ版で満たしているか**: 写真あり版プロフィール・固定投稿とも、4点（創作／写真は同意済みの実在の人物／投稿は運営者が作成／紹介先に出演していない）を満たしている。ただし「出演していない」は photo-consent 3-2 の確認が前提。専門家確認推奨は継続
2. **実在のコスプレイヤー本人と誤認されないか**: 表示名「（キャラ）」と注意書きで文面上は対策できている。「コスプレイヤーキャラ」の語順は「中の人がいるキャラ」とも読めたので、推奨版で「〜コスプレイヤーのキャラ『みお』」に変更。同名の実在のコスプレイヤーの有無は 11/7 までにオーナーが検索で確認
3. **若く見える方向に寄っていないか**: 未成年の想起はなく NG には当たらない。ただし 22歳＋コスプレイヤーで社会人の手がかりがないと「学生」と読まれる余地があるため、冒頭に「会社員」を追加（決定 #18 の趣旨）
4. **文字数**: ディレクターの数えと一致。推奨版も160字以内・280以内。入力画面で要確認
5. **写真なし版の注意書き**: 写真がない間は足りる。写真の文言は入れない方が正しい。実写が出る前に写真あり版へ替える
