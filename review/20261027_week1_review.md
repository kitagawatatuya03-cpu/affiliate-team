## 1. 論点（ディレクターからの4論点の結論と根拠）

### 論点1: 案件なしの日常投稿に「PR」「18歳未満閲覧禁止」は必要か

**結論**
- **(1) 法律（ステマ告示）だけで見れば、案件・商品・サービスに一切触れない日常投稿には、投稿ごとの PR 表記は不要と考えられる。** ただし原文未確認で、判断に微妙な点があるため **専門家確認推奨**（景品表示法に詳しい弁護士）
- **(2) アカウント全体の注意書き（プロフィール・固定投稿）は、案件投稿の代わりにはならない。** 案件投稿は従来どおり、投稿ごとに冒頭近くに PR が必要
- **(3) 18歳未満閲覧禁止は、日常投稿でも付け続けることを推奨する**（法的義務ではなく、未成年保護のための社内ルールとして）
- **(4) 第1週の扱い（推奨）: 現行の CLAUDE.md は「全投稿」と書いているため、表記なしの原文は OK にできない。第1週は「【PR】＋18歳未満閲覧禁止」を付けた修正版で承認②に回す。** 表記なしで運用したい場合は、下の「オーナーへの変更提案」をオーナーが採用し、CLAUDE.md を改定してから（専門家確認も済ませてから）にする

**根拠**
- ステマ告示（令和5年3月28日 内閣府告示第19号、2023年10月1日施行。景品表示法5条3号の指定告示）の対象は「事業者が自己の供給する商品・役務の取引について行う表示」のうち、一般消費者が事業者の表示だと判別しにくいもの。運用基準では「事業者の表示か」と「判別困難か」の2点で判断し、アフィリエイト広告も対象になるとされる（検索結果の抜粋で確認。原文未読）
  - 商品・サービス・ブランド名・リンクのない日常投稿は、特定の商品・役務の「取引について行う表示」に当たりにくい → 告示の対象外と考えられる
  - ただし、次のどれかがあれば、その日常投稿も「事業者の表示」になりうる: 作品名・サービス名・FANZA／DMM の名前、リンク、「明日おすすめ紹介するね」などの予告や示唆、案件投稿へのリプ・引用・スレッドへの連結、案件投稿と同じ画像
  - 「微妙な点」: アカウント全体が収益目的のアフィリエイト運用であることを、当局がどう評価するかの公式な解説は、検索の範囲では見つからなかった
- プロフィール欄の注意書きだけで足りるか: 消費者庁の Q&A でこの点を明示した記述は、検索の範囲では **見つからなかった（未確認）**。ただし運用基準は「表示内容全体から」判別できるかで判断し、PR が小さい・薄い・ハッシュタグに埋もれている場合は判別困難とされる。X の投稿はタイムライン・検索・リポスト・埋め込みでプロフィールと切り離して表示されるため、**案件投稿は投稿単位で判別できる表記が必要**と判断する（厳しい側）
- 18歳未満閲覧禁止を日常投稿でも残す理由:
  - X のセンシティブ設定（メディア設定）は画像・動画に警告を付けるもので、**テキストだけの投稿は隠れない**（X ヘルプの検索抜粋で、メディアに警告を付ける機能であることを確認）
  - 第1週の日常投稿は「入口」として検索・リポストで広く表示される。プロフィールや固定投稿を見ずにフォローした人が、第2週以降の案件投稿を目にすることになる。入口の時点で「成人向けアカウント」と分かるようにしておくのが、未成年保護として安全
  - コストは X 換算で 17 文字分（改行込み）。全案で上限内に収まる（論点2）
- 日常投稿に【PR】を付けることの法的リスク: 広告でない投稿に PR と書いても景品表示法上の問題は生じない。デメリットは「宣伝ばかりのアカウント」に見えて反応が落ちうること（運用面のみ）

### 論点3: 固定投稿の「大人の夜の過ごし方」は X のアダルト要素規制に触れるか

**結論**

**根拠**
- X のアダルトコンテンツポリシー（検索抜粋で確認、原文未読）: アダルトコンテンツは、目立つ場所（プロフィール画像・ヘッダー・リストのバナー・コミュニティのカバー画像・ライブ動画）には置けない。違反は削除、繰り返すと読み取り専用や凍結
