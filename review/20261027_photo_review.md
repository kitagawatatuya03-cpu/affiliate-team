1. **アイコンはすべての投稿の横に表示される**。「案件投稿に写真を付けない」だけでは、案件投稿に実在の女性の顔が並ぶ状態は防げない。ライブチャットの案件投稿には毎回「※写真の人物はこのサービスに出演していません」を入れる
2. ライブチャット紹介は **条件付き継続**。11/13 開始は延期し、早くても 11/20（戦略の代替B）。条件は 3 章
3. **出会い系は、実写アイコンのこのアカウントでは扱わない**（サクラに見えるリスクが最も高い。決定2の保留を「実写のままなら不可」に強める提案）
4. DM は「完全に閉じる」。案件投稿は返信できる相手を制限（フォロー中のアカウント等）。写真の人物への性的リプ・容姿へのリプは返信せず非表示・ブロック
5. 投稿に付ける写真は「顔なし（手元・小物・風景）」を基本にし、顔写真はアイコンのみ。事務服風の写真を投稿に使わない
6. 写真に関する守りのKPIを追加（写真の人物の特定・なりすまし・出演者誤認のリプが1件でも出たら案件投稿停止）
7. photo-consent.md に 14項目追加（2 章）。compliance-checklist.md に「実写」セクション追加（5 章）
8. 戦略書の R4・R7・第4章（アイコン）・第5章（固定投稿方針）が「実在の女性写真を使わない」前提のまま。strategist による改訂とオーナーの確認が必要

### オーナーに判断してほしい点

1. **推奨版で承認②に回すか**（専門家確認推奨のまま進めるか、専門家に確認してから進めるか）。compliance は OK を出していない
2. **写る人はオーナー本人か知り合いか**。compliance としては「オーナー本人」を推奨（知り合いの場合、他人の顔で第三者が書いた一人称の投稿を出すことになり、X の「欺く目的の人物像」に近づく。同意撤回・身バレ時の被害も第三者に及ぶ）
3. **ライブチャットの開始時期**: 11/13 → 11/20 以降に延期（推奨）／条件を満たさなければさらに延期、でよいか
4. **アイコン画像の確認方法**: compliance は画像を見ていない。リポジトリに顔写真を置かない前提で、(a) オーナーが photo-consent 3章で自己チェックし「確認日」だけ記録する、(b) リポジトリ外で compliance に見せる、のどちらにするか
5. **アイコンの服装**: 事務服風（現行ルール）か、私服か。compliance は **私服を推奨**（実在の人物＋医療事務の仕事着＋アダルトアカウントの組み合わせは、医療職の性的イメージ化〔R8〕と、写る人の実際の勤務先での誤認を強める）
6. **写る人の年齢基準**: 18歳以上（現行）に加え「高校等に在学中でない」を必須にするか。compliance の推奨は **20歳以上**（18・19歳は在学中の可能性があり、未成年NGルールの「未成年に見える」に近づく）
7. **出会い系**: 実写アイコンのこのアカウントでは扱わない、でよいか
8. 11/1 までに推奨版の承認②が間に合わない場合: 11/1 夜の「自己紹介は固定したから」の投稿を差し替えるか、開始を遅らせるか

## 1. 差し替え案（固定投稿・プロフィール）の判定

### 1-1 固定投稿（v2 原文）

- **判定: 要修正**（＋専門家確認推奨）
- 該当したチェック項目
  - 共通: 断定・誇大表現がない（誤認を与えない）→ 人物の誤認が残る
  - X（アダルトライン）: アイコン・ヘッダー・固定投稿にアダルト要素がない → 文面は問題なし。ただし画像は未確認
  - 共通: PR表記 → あり（OK）。18歳未満閲覧禁止 → あり（OK）
  - 戦略 R7（サクラ・出演者に見えるリスク）
- 理由
  1. **「写真は本人の同意済みです」の「本人」があいまい**。直前の「うっかり医療事務のみおです」と並ぶと、「みお本人＝写真の人」と読める。結果として「写真の女性が24歳・医療事務で、この投稿を書いている」と受け取られる余地が残る。写る人が知り合いで投稿文を書いていない場合、この読み方は事実と違う
  2. **「キャラ設定で運用中」だけでは、何が創作かが分からない**。「写真の人が自分でキャラを演じている（中の人がいる）」とも読める。年齢・職業・エピソードが創作であることを明示した方がよい
  3. X の Misleading and deceptive identities ポリシー（抜粋）では、仮名アカウントは認められる一方、「存在しない人物を装う」ことを欺く目的の人物像とし、例として「存在しない人物を装うためのコンピュータ生成の人物画像」を挙げている（原文未確認）。**実在の人の顔写真で、存在しない人物（24歳・医療事務のみお）を装う** のは、この例に近い構造。仮名・キャラ運用であることと、写真と投稿者の関係を明示すれば「欺く目的」から遠ざかるが、どこまでで足りるかは原文と運用次第。原文未確認のため **OK にしない**
  4. 「紹介するサービスに私は出ていません」の「私」は、実写化後は「キャラ」か「写真の人」か分からない。出演者誤認を防ぐ目的なら、**「写真の人物は」と主語を明示** した方が確実
  5. 景表法・ステマの観点: アカウント全体の PR 表記（プロフィール・固定投稿）と、案件投稿ごとの PR があれば「事業者の表示であること」は判別できる（消費者庁の運用基準の抜粋）。人物設定そのものがステマ告示に当たるわけではない。ただし、実在の女性の顔で「調べてみた」と紹介する形が、サービスの評価・利用実態について誤認を与えるか（優良誤認の余地）は **専門家確認推奨**
- 修正案: 「結論」の推奨版（固定投稿）
- 根拠
  - X「Misleading and deceptive identities policy」 https://help.twitter.com/articles/253551 （検索結果の抜粋のみ。**原文未確認**。現行URLは https://help.x.com/en/rules-and-policies/ 配下と思われるが取得不可）
  - 景品表示法 5条3号・令和5年内閣府告示第19号（一般消費者が事業者の表示であることを判別することが困難である表示）と運用基準。解説資料の抜粋で確認: https://keiyaku-watch.jp/download/01030_stealth_marketing/ 、 https://www.pwc.com/jp/ja/legal/news/assets/legal-20230927-2.pdf （消費者庁の原文は**未確認**）
  - CLAUDE.md 必須表記、rules/brand-voice.md 11行目（関係を偽らない）

### 1-2 プロフィール（v2 原文）

- **判定: 要修正**（＋専門家確認推奨）
- 該当したチェック項目: 1-1 と同じ。加えて戦略 R8（医療関連の誤認）
- 理由
  1. 冒頭が「病院で働く医療事務（24）」と事実の言い切りになっている。イラストのときは見た目で架空と分かったが、**実写の顔の横では「写真の人が実際に病院で働く24歳」と読まれる**。写る人の実際の勤務先で誤認・風評が起きるおそれもある
  2. 「※キャラ設定で運用中／写真は本人の同意済み」は 1-1 の理由1・2と同じあいまいさが残る
  3. 投稿者が写真の人でない場合の誤認（知り合いのケース）が解消されていない
- 修正案: 「結論」の推奨版（プロフィール）。冒頭を「医療事務キャラ『みお』（24歳設定）」にして、職業・年齢が設定であることを最初の一文で示した
- 根拠: 1-1 と同じ。rules/brand-voice.md 38行目（勤務先が特定される情報を出さない）

### 1-3 推奨版について（compliance の扱い）

- 推奨版は、1-1・1-2 の誤認ポイントを文面上は解消している
- ただし **「専門家確認推奨」** を外せない。理由: (1) X の Authenticity／deceptive identities ポリシー原文を読めていない、(2) 実在の人の顔＋架空の年齢・職業＋アダルト案件という組み合わせの評価は先例が乏しい、(3) 写る人が知り合いの場合の肖像・名誉・プライバシー面の評価
- 推奨版を使う前提: 写る人について photo-consent の追加項目（2章）を満たしていること。特に「ライブチャット・アダルト作品に出演していない」ことの確認

## 3. 実写化で強まるリスクと、戦略・カレンダーで変えるべき運用

### 3-1 強まるリスク

| リスク | 実写化での変化 | 評価 |
|---|---|---|
| ライブチャットの出演者・サクラに見える（R7） | イラストのときは「架空」が見た目で伝わった。実写では、**実在の女性の顔の横に「ライブチャット」「PR」「リンク」が並ぶ**。アイコンは案件投稿にも表示されるので、写真を付けないだけでは防げない | 大きく上昇 |
| X の deceptive identities（R7） | 実在の顔で存在しない人物を装う構造になる（1章）。注意書きで軽減できるが、原文未確認 | 上昇。専門家確認推奨 |
| 身バレ（オーナー本人／知り合い） | 逆画像検索・知人の目視で特定されうる。アダルトアカウントとの結びつきは取り消しにくい | 新たに発生（重大） |
| 性的リプ・容姿へのリプ・DM要求 | 実在の人の顔に向けた性的リプは、イラストより増え、写る人本人への性的な扱いになる | 大きく上昇 |
| 医療職の性的イメージ化（R8） | 事務服風の実写は「実在の医療事務の女性」に見える | 上昇 |
| ストーカー・つきまとい | 夜勤のシフト（木曜夜〜金曜朝）・通勤の話が、実在の人物の行動パターンとして読まれる | 新たに発生 |
| 出会い系（保留中） | 実在女性の顔のアカウントが出会い系を紹介すると、ほぼサクラに見える | 実写のままでは扱えない水準 |

### 3-2 ライブチャット紹介を続けてよいか

- **結論: 条件付きで継続。11/13 開始は延期を推奨（早くても 11/20、戦略の代替B）**
- 条件（すべて満たすまで開始しない）
  1. 規約原文の確認（R1）が済んでいる: X の Authenticity／deceptive identities／adult content、DMMアフィリエイトのガイドライン。今回も取得できていない
  2. 推奨版の固定投稿・プロフィールが公開済み
  3. 実写化後、日常投稿で **1週間以上**、「出てるの？」「本人？」系のリプや身バレの兆候がない
  4. 各ライブチャット投稿に **「※写真の人物はこのサービスに出演していません」** を入れる（PR・18歳以上対象・料金条件に加えて）
  5. 一人称の体験・感想に寄せない。「男の人ってこういうの使うんだ…調べてみた」の型は、実写の顔の横では「私が関わっている」と読まれやすい。**「公式ページのしくみを整理してみた」の説明型** に寄せる（「気になる」「ちょっとやってみたいかも」等は不可）
  6. 出演者の紹介・個人ページへのリンク・出演者の画像は、1か月目に限らず **実写アイコンの間は行わない**
  7. ライブチャットの投稿は「返信できるアカウント」を制限する（「話そう」「君と話したい」系のスレッドを作らせない）
  8. 停止ルール: 出演者・サクラと誤認したリプ、写る人の特定につながるリプが **1件でも** 出たら、ライブチャット投稿を止めてオーナーに報告
- 上記を満たせない、またはオーナーが写る人を知り合いにする場合は、**ライブチャット紹介は行わず動画のみ** にすることを推奨

### 3-3 戦略・カレンダーで変えるべき運用（「案件投稿に写真を付けない」以外）

1. **投稿の写真は顔なしを基本**（手元・小物・食べ物・空）。顔写真はアイコンのみ。事務服風・仕事中の写真を投稿に使わない。投稿に写真を付ける場合は、その写真も drafts に「写真あり」と明記して compliance チェック対象にする
2. **DM は完全に閉じる**（戦略の「フォロー中のみ」案は採らない）
3. **リプ対応ルールの改訂**: 戦略 第9章3「もらったリプには、その日のうちに返す」を、「日常の話題への普通のリプにだけ返す。容姿・身体・写真・会いたい・どこの病院 系は返信せず非表示、悪質ならブロック・報告」に変更。ミュートワードを設定
4. **生活パターンをぼかす**: 夜勤の曜日固定（木曜夜〜金曜朝）は、実在の人物の行動として読まれる。曜日を固定しない、または「今週のどこか」程度にする（カレンダーの「金曜朝＝夜勤明け」の定番化は見直し推奨）。通勤経路・駅・天気から地域が分かる書き方をしない
5. **予約投稿の時刻と写る人の実生活を切り離す**（知り合いの場合、本人の実際の勤務時間と投稿時間が一致しないこと自体は問題ないが、本人が見られて困る時間帯の話題を避ける）
6. **守りのKPIを追加**（戦略 第10章）: 「写真の人物の特定・なりすまし発見・出演者誤認のリプ・写真への性的リプの急増」→ 1件で案件投稿停止、オーナー報告
7. **週1回の点検に追加**: 逆画像検索（アイコン画像でなりすましがないか）、プロフィール・固定投稿の注意書きと実態が一致しているか
8. **出会い系**: 実写アイコンの間は、このアカウントでは扱わない（決定2の扱いをオーナーに再確認）
9. **戦略書の改訂が必要な箇所**（strategist 担当）: 第4章「アイコン・ヘッダー」（イラスト推奨・実在女性写真不使用）、第5章 2（「実在の人物・医療機関とは関係ありません」）、R4（「人物の露出なしのイラストか小物」）、R7 対策（「実在の女性写真を使わない」）、オーナーに決めてほしいこと「アイコン」。現状は決定#12〜#14と矛盾している
10. オーナー決定 #3「※キャラクター運用アカウントです」と #13 の関係を整理（#13 で置き換えたのか、併記なのか）。推奨版は「キャラ設定のアカウント」で #3 の趣旨を含む
