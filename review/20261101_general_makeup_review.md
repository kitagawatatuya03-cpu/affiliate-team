## 第2章 論点A: プロフィールに「PRを含みます」を今入れるか

### 推奨: **今は入れない**。ただし CLAUDE.md の変更（オーナー決定）が前提

理由:
1. **法律上は今は不要**。ステマ規制（景品表示法5条3号の指定告示、2023年10月施行）の対象は「事業者の表示」、つまり広告主が表示内容に関与した投稿。当面はアフィリエイトも商品提供も依頼もないので、投稿は事業者の表示に当たらず、PR 表記の義務は生じない
2. **案件がないのに「PRを含みます」と書くと事実と合わない**。また X のプロフィールにも同じ文字列があり、結びつきの手がかりが1つ増える
3. ただし、**CLAUDE.md の「プロフィール・固定投稿: 常に掲載」は現行ルール**。ルールのまま PR なしで出すと社内ルール違反になる。私（compliance）には例外を認める権限がないので、オーナーが CLAUDE.md を変えるか、変えないなら PR 入りの版を使うか、どちらかを決めてください

いつ入れるか（変更後も厳しめに）:
- 次のどれか **いちばん早い時点の前** に入れる
  1. ASP にこのアカウントを媒体として登録申請する
  2. 商品の無償提供・投稿の依頼を受ける（金銭がなくても広告扱いになりうる）
  3. 最初の案件投稿
- 入れるときは compliance のチェックを通す

### CLAUDE.md の変更案（オーナー承認が必要。私は書き換えていません）

「必須表記」の該当行を次のように差し替え:
```
- プロフィール・固定投稿: 案件投稿をするアカウントは「PRを含みます」等、アカウント全体の注意書きを常に掲載。
  収益化前の一般ライン（コスメイク・ウィッグアレンジの Instagram・Threads）は不要。ただし
  ①ASP への媒体登録の申請 ②商品・サービスの無償提供や投稿依頼の受諾 ③最初の案件投稿
  のいずれか早い時点より前に掲載する（掲載前に compliance チェック）
```
「事業ライン」の下に追加（収益化に備えて今決めておく）:
```
- 一般ラインはキャラ設定で運用するが、特定の商品・サービスの使用感・効果を創作のエピソードで語らない。
  収益化後の紹介は、運営者が実際に使った事実の範囲に限る（架空の使用体験で推奨する広告は、
  景品表示法の優良誤認・ステマの論点。専門家確認推奨）
```

あわせて、オーナーに確認してほしいこと:
- brand-voice（一般ライン）は「会社員のコスプレイヤー『みお』」だが、戦略 v2（第1章・第12章）は「一般ラインのキャラはコスプレイヤーにしない」としている。今回の修正では「コスプレイヤー」「会社員」を **書かない** ことで両立させた（キャラの設定は変えず、表に出す語だけ減らす）。この扱いでよいか

## 第3章 写真の共通条件（全投稿。承認②の条件として付けてください）

writer の指示（顔なし・目元アップなし・ロゴ品番なし・場所の分かるものなし・X と同じ写真なし）は適切。次を追加:

1. **X の写真に写ったウィッグは IG・Threads で使わない**（逆も同じ）。色違い・同じ型も避ける
2. **手**: ネイルは X の写真と別の色・デザイン、または何も塗らない。指輪・ブレスレット・腕時計は外す。目立つほくろ・傷・タトゥーが写らない角度
3. **背景・小物**: X の写真に写った机・壁・タオル・小皿・ウィッグスタンド・ライトを使わない（X のヘッダーはウィッグスタンド・メイク道具の写真なので特に注意）
4. **化粧品は中身だけ**: 容器・パレットの形・ブラシの柄の刻印でもブランドが分かるので、スウォッチの写真に容器を入れない
5. 位置情報をつけない（投稿の「場所を追加」を使わない）
6. **着用した後ろ姿は使わない**（推奨案ではすべて外した）。使う場合は、X で使っていないウィッグ・首元の詰まった無地の服・首すじや肩の肌を強調しない・鏡や窓に顔が映らない、をすべて満たすこと
