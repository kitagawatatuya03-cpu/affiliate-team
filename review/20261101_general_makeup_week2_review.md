## 第1章 組み合わせと事実の整合（ライターのメモの検証）

### 1-1 ライターのメモの条件は正しいか
- 「11/16 案A は IG 3日とも案A の場合のみ」→ **正しい**。さらに IG 11/15 案A のキャプション・7枚目も同じ条件
- 「11/10 案A は IG 11/11 案A に合わせた文」→ 正しい
- 「11/15 案B は IG 11/15 案A と同じ内容 → Threads は案A」→ 正しい（同じ日に同じ話を2回出さない）
- 「11/13 案B は IG 11/13 案A の6枚目とほぼ同じ → Threads は案A」→ 正しい。ただし案A にも別の矛盾がある（1-2 の③）
- **メモにない矛盾**: Threads 11/14 案B「次は、のせる前に手の甲で重ねる順番を決めてからにします」は、IG 11/13 案B「いまは先に手の甲で練習してから始めています」と **前後が逆**（もうやっていることを「次はやる」と書いている）。IG 11/13 案B と Threads 11/14 案B は同時に使わない
- 11/13 IG の「メイクとウィッグを交互に」の案（メモ）は、IG 11/15 案A・Threads 11/16 案A を使えなくなるうえ、IG の案B の写真の危険が増えるので推奨しない

### 1-2 推奨の組み合わせで直した事実のずれ（架空の体験談の一貫性）
創作の体験談でも、投稿どうしで食い違うと「作り話の宣伝」に見え、信頼を失います（収益化後は景品表示法の優良誤認の論点にもつながる）。
1. **IG 11/11 案A**: 前日の Threads 11/10 で「ハーフアップから始めることにしました」と書いた翌日に、「前に〜したことがあって。それからは〜ようにしています」と長く続けている習慣のように書くと合わない → 「最初は〜」「やりなおすときに〜ようにしました」
2. **IG 11/15 案A**: 「前に質問した3つのアレンジ」の質問は Threads 11/9 で、Instagram では質問していない → 「今週順番に練習してきた3つのアレンジ」
3. **Threads 11/13 案A**: 「ゆるめに、同じ強さで編むのがいちばんむずかしい」と、11/15・11/16 の「いちばん手ごわかったのは編み込み（足す毛の量）」が食い違う → 「思っていたよりむずかしい」
4. **Threads 11/16 案A**: 11/16 は月曜。月曜に「今週は〜練習しました」「来週も」と書くと日付が合わない → 「この1週間で」「今週も」

## 第2章 写真の共通条件（全 IG 投稿。承認②の条件として付けてください）

下書きの「写真の共通ルール」（顔・人物なし、着用した後ろ姿なし、ネイルなし・アクセサリーを外す、化粧品の容器・刻印なし、X で使ったウィッグ・スタンド・小物を使わない、無地の背景、位置情報オフ・Exif 削除、写真はリポジトリに置かない）は適切。次を追加:

1. **背景の布を X と分ける**: X の同週の写真（11/10 アトマイザー、11/11 ヒール、11/12 仮面）はすべて「無地の布の上」で撮る指示。**同じ布・同じ色の布を IG で使わない**。IG は紙（無地の画用紙など）にするか、X と明らかに違う色・素材の布にする
2. **ウィッグ**: 11/11・11/13・11/15 で同じウィッグを使うのはよいが、X の 11/8（承認済み）の写真のウィッグ・スタンドとは別のもの（色違い・同じ型も避ける）
3. **髪型**: 学生を思わせる形（左右2本のおさげ、ツインテール）にしない。黒髪のストレートに編み込みを入れた写真は制服の連想を招きやすいので、ウィッグの色は黒以外を推奨
4. **イラスト**（IG 11/15 7枚目）: 髪型だけ。顔・人物は描かない。頭の形を入れる場合も、丸く大きな頭など幼い頭身にしない
